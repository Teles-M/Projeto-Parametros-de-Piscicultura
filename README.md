# Monitoramento de Parâmetros na Psicultura

- O problema: As variações bruscas na qualidade da água dos tanques (como oxigênio baixo ou temperatura inadequada) podem dizimar uma produção inteira de tambaqui em poucas horas.
- O sistema resolve essa dor, ao integrar funcionalidades de monitoramento e correção desses parâmetros.
